## Описание

Проект «Лабиринты» — консольная программа для генерации и решения лабиринтов различной сложности. Приложение позволяет:

- создавать лабиринты с помощью нескольких алгоритмов генерации;
- находить кратчайший путь между точками **O** (начало) и **X** (конец);
- учитывать типы поверхности с разными стоимостями прохождения;
- визуализировать результат в консоли с помощью **ASCII** или **Unicode** псевдографики.

Интерфейс приложения полностью основан на CLI и поддерживает дополнительные флаги для гибкой настройки вывода.

---

## Функциональные требования

- Реализация 2-х алгоритмов генерации лабиринта:
  - Поиск в глубину (DFS);
  - Алгоритм Прима.
- Реализация 2-х алгоритмов поиска пути:
  - A*;
  - Дейкстра (с учётом стоимости клетки).
- Ввод конфигурации лабиринта, начальной и конечной точки через CLI:
  - `--algorithm` — выбор алгоритма;
  - `--width`, `--height` — размеры лабиринта;
  - `--start`, `--end` — координаты точек;
  - `--file`, `--output` — ввод и сохранение файлов;

---

## Дополнительные параметры CLI

### Псевдографика и визуализация

- `--unicode` — включение Unicode псевдографики;
- `--frame` — отображение рамки вокруг лабиринта;
- `--costs` — указание JSON-файла с типами покрытия (`terrain.json`);
- `--showterrain` — визуализация типов поверхности при выводе.

---

## Примеры CLI-команд

### Генерация лабиринта

**DFS-алгоритм:**
```bash
dotnet run --project ./src/Labyrinths.csproj -- generate --algorithm=dfs --width=30 --height=30 --output=maze1.txt
```

**Алгоритм Прима:**
```bash
dotnet run --project ./src/Labyrinths.csproj -- generate --algorithm=prim --width=30 --height=30 --output=maze2.txt
```

**Генерация лабиринта (DFS + Unicode + Frame):**
```bash
dotnet run --project ./src/Labyrinths.csproj -- generate --algorithm=dfs --width=30 --height=30 --output=maze_unicode.txt --unicode --frame
```

---

### Решение лабиринта

**Алгоритм A*:**
```bash
dotnet run --project ./src/Labyrinths.csproj -- solve --algorithm=astar --file=maze1.txt --start=0,0 --end=29,29 --output=solution_maze1.txt
```

**Алгоритм Дейкстры:**
```bash
dotnet run --project ./src/Labyrinths.csproj -- solve --algorithm=dijkstra --file=maze2.txt --start=0,0 --end=29,29 --output=solution_maze2.txt
```

**Решение лабиринта (A* + Terrain Costs + Unicode + Frame):**
```bash
dotnet run --project ./src/Labyrinths.csproj -- solve --algorithm=astar --file=maze_unicode.txt --start=0,0 --end=29,29 --output=solution_unicode.txt --costs=terrain.json --showterrain --unicode --frame
```

---

## Примечания

- Координаты точек **`--start`** и **`--end`** задаются в формате `x,y`,  
  при этом **нумерация начинается с нуля** (например, `--start=0,0` — верхний левый угол лабиринта).
- При использовании флага **`--unicode`** результат в `.txt` файле может отображаться некорректно,  
  что связано с особенностями текстового формата и кодировки символов. В консоли отображение будет корректным и визуально выровненным.

## Пример карты покрытий terrain.json

Файл `terrain.json` задаёт типы поверхностей с различной стоимостью передвижения.  
Чем больше `cost`, тем "хуже" поверхность для движения (например, болото = 3.0, песок = 2.0, бонус = 0.3).

```json
  { "x": 5, "y": 1, "cost": 0.6 }, { "x": 6, "y": 1, "cost": 0.6 }, { "x": 7, "y": 1, "cost": 0.6 },

  { "x": 10, "y": 2, "cost": 2.0 }, { "x": 11, "y": 2, "cost": 2.0 }, { "x": 12, "y": 2, "cost": 2.0 },
  { "x": 13, "y": 3, "cost": 2.0 }, { "x": 14, "y": 3, "cost": 2.0 }, { "x": 15, "y": 3, "cost": 2.0 },

  { "x": 18, "y": 4, "cost": 3.0 }, { "x": 19, "y": 4, "cost": 3.0 }, { "x": 20, "y": 5, "cost": 3.0 },
  { "x": 21, "y": 5, "cost": 3.0 }, { "x": 22, "y": 6, "cost": 3.0 }, { "x": 23, "y": 6, "cost": 3.0 },

  { "x": 4, "y": 10, "cost": 2.0 }, { "x": 5, "y": 10, "cost": 2.0 }, { "x": 6, "y": 10, "cost": 2.0 },
  { "x": 4, "y": 11, "cost": 2.0 }, { "x": 5, "y": 11, "cost": 2.0 }, { "x": 6, "y": 11, "cost": 2.0 },

  { "x": 8, "y": 13, "cost": 0.6 }, { "x": 9, "y": 13, "cost": 0.6 }, { "x": 10, "y": 13, "cost": 0.6 },
  { "x": 11, "y": 13, "cost": 0.6 }, { "x": 12, "y": 13, "cost": 0.6 },

  { "x": 14, "y": 15, "cost": 0.3 }, { "x": 15, "y": 15, "cost": 0.3 }, { "x": 16, "y": 15, "cost": 0.3 },
  { "x": 17, "y": 16, "cost": 0.3 }, { "x": 18, "y": 16, "cost": 0.3 }, { "x": 19, "y": 16, "cost": 0.3 }
]
```

Файл можно использовать для демонстрации работы флагов `--costs` и `--showterrain`.
